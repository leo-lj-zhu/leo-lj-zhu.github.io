# Leo Zhu’s academic website

[View the site](https://leo-lj-zhu.github.io/).

The site uses static HTML and CSS. GitHub Pages publishes from the root of `main` on push. The `.nojekyll` file tells Pages to serve the files directly.

## Local preview

Run `python3 -m http.server 8000` from the repository root and open `http://localhost:8000/`.

Edit `index.html` to update the profile and research entries. Replace `cv/Leo_Zhu_CV.pdf` to update the linked public CV.
